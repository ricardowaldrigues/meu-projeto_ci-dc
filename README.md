# meu-projeto_ci/dc
O objetivo deste projeto é demostrar o funcionamento e controle de um LED com um microcontrolador esp32 utilizando a linguagem pyton
Componentes utilizados:
Microcontrolador Esp32 ,LED ,protoboard ,jumpers.
descritivo de funcionamento:
o programa envia um sinal digital,nivel lógico 1,(3,3v)através da porta digital GPI02 permitindo assim o fluxo de corrente pelo resistor e acendendo um LED.o ciclo se repete no intervalo de um segundo.
